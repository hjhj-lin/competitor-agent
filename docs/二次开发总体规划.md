---

## 一、项目现状分析

### 1.1 项目概述

企业竞品分析多Agent平台：用户输入公司名，4个AI Agent（采集→分析→报告→审核）串行协作，自动生成竞品分析报告。

**技术栈**：Spring Boot 3.4.5 + Spring AI 1.1.3 + MyBatis-Plus 3.5.6 + MySQL + JWT + SSE + 原生JS前端

### 1.2 已完成能力（Day 1-16）

#### 模块1：Agent框架重构（Day 17）

**Step 17-1: BaseReActAgent抽象类**

```java
public abstract class BaseReActAgent implements Agent {
    protected final ChatClient chatClient;
    protected final SearchTools searchTools;
    protected final AgentExecutionMapper agentExecutionMapper;

    @Override
    public AgentResult execute(AgentContext context) {
        // 模板方法：固定骨架
        long start = System.currentTimeMillis();
        AgentExecution execution = createExecution(context);
        try {
            String question = buildQuestion(context);        // 子类实现
            String result = chatClient.prompt()
                .system(getSystemPrompt())                   // 子类实现
                .user(question)
                .tools(searchTools)
                .call()
                .content();
            return handleSuccess(context, result, execution, start);
        } catch (Exception e) {
            return handleFailure(execution, e, start);
        }
    }

    // 子类只需实现3个方法
    protected abstract String getSystemPrompt();
    protected abstract String buildQuestion(AgentContext context);
    protected abstract String getResultKey();
}
```

**Step 17-2~5: 4个Agent瘦身**

改造后每个Agent只需15行：
```java
@Component
public class CollectAgent extends BaseReActAgent {
    @Override protected String getSystemPrompt() { return COLLECT_SYSTEM_PROMPT; }
    @Override protected String buildQuestion(AgentContext ctx) {
        return String.format("请采集「%s」的竞品信息...", ctx.getCompanyName());
    }
    @Override protected String getResultKey() { return "collectResult"; }
    @Override public String getName() { return "collect"; }
    @Override public String getDescription() { return "采集Agent"; }
}
```
